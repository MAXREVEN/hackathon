# 🎙️I'm Lost : Pipeline Automatisé de Transcription Audio & Résumé par IA

Ce projet automatise la transformation d'enregistrements vocaux vidéos ou notes audio en textes propres structurés et résumés avec envoi automatique du résultat final par notification.
Il combine n8n pour l'orchestration, OpenAI Whisper pour la reconnaissance vocale (ASR) , ollama 3.2 : un LLM modèle local (via Tailscale) pour le nettoyage éditorial et le résumé et gére une diffusion instantanée.
